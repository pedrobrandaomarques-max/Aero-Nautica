#  Aero-Náutica | Agência de Turismo

> Site institucional de uma agência de turismo fictícia, desenvolvido para apresentar destinos, resorts e pacotes de viagem.

## Sobre o projeto

O **Aero-Náutica** é um projeto de desenvolvimento web com temática de turismo. O site reúne páginas dedicadas à apresentação de destinos, opções de resorts e pacotes de viagem, com navegação entre as seções e elementos visuais como imagens, cartões e um carrossel na página inicial.

O objetivo foi praticar a organização de páginas HTML e a criação de layouts com CSS e **Bootstrap 4**. Trata-se de uma **demonstração acadêmica**, não de uma agência em funcionamento ou de um sistema de compras e reservas.

##Origem e aprendizado

Este projeto faz parte dos meus **primeiros trabalhos de desenvolvimento web**, realizados durante o **curso básico de HTML e CSS no SENAC**.

Foi uma oportunidade de avançar no aprendizado de estruturação de páginas, estilização de interfaces, utilização de componentes prontos, organização de arquivos e navegação entre diferentes páginas de um mesmo site.

##  Páginas do site

| Página | Conteúdo |
| --- | --- |
| **Início** (`index.html`) | Carrossel de imagens, apresentação visual de destinos como Chile, Grécia e Holanda e banner promocional. |
| **Resorts** (`resort.html`) | Galeria de cartões com imagens e exemplos de opções de resorts. |
| **Pacotes** (`pacotes.html`) | Cartões de pacotes demonstrativos para Curitiba, Itália, Holanda e Israel, com informações ilustrativas de viagem e hospedagem. |

## Tecnologias utilizadas

- **HTML5:** estrutura e conteúdo das páginas.
- **CSS3:** personalização visual dos elementos.
- **Bootstrap 4:** sistema de grid, navegação, cartões e carrossel.
- **JavaScript e jQuery:** bibliotecas incluídas para dar suporte aos componentes interativos do Bootstrap.

O código também utiliza uma estrutura inicial gerada com **LayoutIt!**, que foi adaptada para a proposta visual do projeto.
